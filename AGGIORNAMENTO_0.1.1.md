# Aggiornamento 0.1.1

Correzioni del launcher Windows:

- rilevamento di `py` o `python`;
- creazione automatica dell'ambiente `.venv`;
- installazione automatica di `PySide6` e `platformdirs`;
- avvio con l'interprete dell'ambiente virtuale;
- messaggi di errore leggibili;
- controllo preventivo delle dipendenze in `run.py`;
- aggiunto il launcher evidente `Avvia_Local_AI_Bridge.bat`.

Al primo avvio è necessaria una connessione Internet per installare le dipendenze Python.
