# Local AI Bridge 0.1.8

Release focalizzata sulla verifica post-applicazione e sulla cronologia.

- dopo **Applica piano** viene proposto di eseguire i controlli rilevati;
- gli esiti vengono memorizzati nella stessa sessione del backup;
- la cronologia mostra file coinvolti e stato dei test;
- selezionando una sessione si vedono origine, file ed esiti;
- le sessioni delle versioni precedenti restano leggibili.

Il rollback resta sempre esplicito: un test fallito non annulla automaticamente le modifiche.
